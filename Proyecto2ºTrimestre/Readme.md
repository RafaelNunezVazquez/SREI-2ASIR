El proyecto consiste en desplegar y administrar un servidor basado en Ubuntu Server 22.04 que integra servicios web, bases de datos, DNS y acceso remoto seguro.
Se utilizan Apache y PHP para alojar páginas web dinámicas, MySQL para gestionar los datos, BIND9 para la resolución de nombres y OpenSSH junto con SFTP para la administración remota y la transferencia segura de archivos.
Finalmente, se desarrolla un script en Bash que automatiza la creación de subdominios, alojamientos web, bases de datos y usuarios, simplificando las tareas habituales de administración del servidor.
El proyecto pretende disponer de un servidor que permita:
- Alojar páginas web y ejecutar aplicaciones PHP.
- Crear y gestionar bases de datos MySQL.
- Acceder a los servicios mediante nombres de dominio.
- Administrar el sistema remotamente por SSH.
- Transferir archivos mediante conexiones seguras.
- Crear nuevos alojamientos, bases de datos y usuarios de forma automatizada.
- Comprobar el funcionamiento de los servicios mediante pruebas desde el propio servidor y desde equipos clientes.
