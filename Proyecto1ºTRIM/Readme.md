# Proyecto de Servidor Web – SREI (1.º Trimestre)

## 📌 Descripción del proyecto

Este proyecto consiste en la instalación y configuración de un servidor web basado en **Ubuntu Server**, integrando diferentes tecnologías para alojar sitios web, gestionar bases de datos y ejecutar aplicaciones web desarrolladas con PHP y Python.

El objetivo es aprender a desplegar y administrar servicios web en Linux, configurar dominios virtuales y poner en funcionamiento aplicaciones web mediante diferentes tecnologías.

## 🛠️ Tecnologías y servicios utilizados

- **Ubuntu Server:** sistema operativo del servidor.
- **Apache2:** servidor web y gestión de hosts virtuales.
- **MySQL:** sistema de gestión de bases de datos.
- **PHP:** desarrollo y ejecución de páginas web dinámicas.
- **WordPress:** instalación y configuración de un gestor de contenidos conectado a MySQL.
- **Python y Flask:** desarrollo de una aplicación web de prueba.
- **mod_wsgi:** integración de aplicaciones Python con Apache.
- **UFW:** configuración del cortafuegos para permitir el tráfico HTTP y HTTPS.

## ⚙️ Tareas realizadas

- Instalación y actualización de Ubuntu Server.
- Instalación y configuración de Apache2, PHP y MySQL.
- Creación de dos hosts virtuales: `centro.intranet` y `departamentos.centro.intranet`.
- Configuración de directorios web, permisos y archivos de configuración de Apache.
- Comprobación del funcionamiento de páginas HTML y PHP.
- Creación de una base de datos y un usuario específico para WordPress.
- Instalación y configuración de WordPress, integrándolo con MySQL.
- Instalación y habilitación de `mod_wsgi` y las dependencias de Python.
- Desarrollo de una aplicación de prueba con Flask y configuración para servirla mediante Apache.

## 🎯 Objetivos y resultados

Al finalizar el proyecto, se dispone de un entorno de servidor web capaz de alojar diferentes sitios mediante hosts virtuales, ejecutar páginas dinámicas en PHP, gestionar contenidos con WordPress y servir una aplicación web desarrollada con Python y Flask.

Este trabajo permite adquirir conocimientos prácticos sobre administración de servidores Linux, alojamiento web, gestión de bases de datos y despliegue de aplicaciones web.

## 📚 Ámbito formativo

Proyecto práctico del módulo de **Servicios de Red e Internet (SREI)** del ciclo formativo de Administración de Sistemas Informáticos en Red (ASIR).
